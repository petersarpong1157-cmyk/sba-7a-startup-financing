# Figures

This folder is reserved for the three publication-quality figures generated by `code/sba_7a_analysis.R`.

Expected files:

1. `Figure_1_Median_Startup_Loan.png` — Median SBA 7(a) loan amount for startup businesses, FY2010-FY2025.
2. `Figure_2_Startup_Share.png` — Startup share of the analytical sample, FY2010-FY2025.
3. `Figure_3_Startup_Share_by_NAICS.png` — Startup share by two-digit NAICS industry.

The figures are derived from the same verified analytical sample used in the working paper. Figure 2's denominator is the startup-plus-established analytical sample, not all SBA 7(a) loans.
